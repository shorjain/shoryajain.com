# shoryajain.com

Personal portfolio of Shorya Jain — Math & CS at NYU Courant.

Live at **https://shoryajain.com**

Plain HTML, CSS and vanilla JavaScript, no build step. Hosted on GitHub Pages.

- `index.html` — page structure
- `styles.css` — all styling (dark/light themes)
- `main.js` — content (edit the `SKILLS`, `PROJECTS`, `EXPERIENCE` arrays at the top) and all interactions: custom cursor, scroll reveals, section tracker, j/k keyboard nav, live forecast demo, live GitHub pulse

Run locally:

```sh
python3 -m http.server 8000
```
